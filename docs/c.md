# Heterogenous namespace

In cases where there is not a continuous namespace, we can establish a _forest_. I can add a domain which is in a different domain space and create a _trust relationship_. A forest is a collection of _trees_ in different name spaces. The enterprise admins group can control the entire forest.

<figure>
<img src = "https://jor-donegal.github.io/EnterpriseAD26/images/fig2.png">

There is a _two-way transitive trust_ between electric-petrol.ie and solar-sweets.ie, therefore all the domains have trust relationships; users in __solar-sweets.ie__ can give rights to domain local accounts in __buncrana.electric-petrol.ie__ if required, and vice versa.
